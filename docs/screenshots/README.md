Screenshots and other images for GLB — test confirmations, tutorial
walkthroughs, before/after shots, etc.

Committed as regular files (not Git LFS), since GLB is a small,
low-volume repo. If this folder starts accumulating a lot of large or
frequently-changing images, revisit that — binary files bloat git
history permanently even after deletion.

Suggested naming: `<topic>-<context>-<date>.png`, e.g.
`cachyos-konsole-nerdfont-2026-08-05.png`.
