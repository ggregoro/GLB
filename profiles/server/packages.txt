# GLB profile: server
#
# Aimed at someone newer to server administration who wants a safe,
# complete baseline (firewall, backups, intrusion protection) without
# researching best practices themselves — same "here's what's good"
# value prop as developer, applied to server admin. Not
# aimed at someone who already has an opinionated stack (they'd set it
# up themselves anyway). See CLAUDE.md (2026-08-07) for the audience
# decision and the forks below.
#
# Package names are resolved per-distro before being passed to your
# package manager (apt/dnf/pacman/zypper). See _GLB_PACKAGE_OVERRIDES
# in lib/package.sh for the few that aren't the same everywhere.

# Shell/prompt foundation — same unified bash/zsh/fish + Starship setup
# as the other profiles (see dotfiles/). Doubly useful here for telling
# apart SSH sessions into different boxes.
git
curl
zsh
fish
fzf
eza
bat
zoxide
bash-completion    # loads glb's completion file - see lib/completions.sh
unzip              # needed for the font extras.txt entry

# Live resource monitor — same pick as default (btop, see CLAUDE.md
# 2026-08-09; superseded the original htop-over-btop call from
# 2026-08-06).
btop

# File manager — same pairing as default (ranger + yazi, see CLAUDE.md
# 2026-08-13): ranger as the plain-package baseline, yazi (extras.txt)
# as the stronger alternative kept alongside it, not replacing it.
ranger

# snapd - needed for the snap extras.txt entry below (yazi). Confirmed
# in apt's index (Pop!_OS/Debian/Ubuntu). Not in Arch/pacman's official
# repos at all (AUR-only). Confirmed real gap on zypper too (2026-08-13,
# openSUSE Tumbleweed VM, real restore): `zypper info snapd` reports
# "package 'snapd' not found" in the default repos — snap/yazi simply
# don't install as a result, same known-gap treatment as lazygit on
# Fedora/dnf rather than chasing a non-default OBS snapd repo. dnf
# unverified.
snapd

# Firewall — ufw chosen over firewalld: simpler allow/deny rule syntax
# is easier for a newcomer to reason about than firewalld's zone model.
ufw

# Backup — rsync for transfers, restic for a real backup tool (chosen
# over borgbackup: simpler single-binary CLI and repo model, easier
# starting point for someone new to backup strategy).
rsync
restic

# Intrusion protection — well-known, standard choice for SSH brute-force
# protection on a fresh server.
fail2ban

# Not included yet: unattended security updates (apt's
# unattended-upgrades / dnf's dnf-automatic have no equivalent single
# package on pacman/zypper — Arch's rolling-release model has no
# standard package for this at all, and openSUSE's story is a
# zypper-cron script, not a plain package). Doesn't fit the current
# "<generic-name>:<package-manager> override" model since two of the
# four managers have no package to map to. Needs either a real
# per-distro opt-out mechanism or an extras.txt-style script install
# before this can be added — see docs/ROADMAP.md.
