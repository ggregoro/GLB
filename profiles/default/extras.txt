# GLB profile: default — extras (installs outside apt/dnf/pacman/zypper)
#
# Format: <method> <name> <spec>
#   curl <name> <url>       - runs `curl -fsSL <url> | bash`. <name> is
#                              checked with `command -v` to detect an
#                              existing install.
#   flatpak <name> <app-id> - ensures the flathub remote, then
#                              `flatpak install -y flathub <app-id>`.
#                              <name> is just a display label; <app-id>
#                              is checked via `flatpak info`.
#   font <name> <zip-url>   - downloads a Nerd Fonts release zip,
#                              extracts it into
#                              ~/.local/share/fonts/<name>, then runs
#                              `fc-cache -f`. <name> becomes the install
#                              directory, so no spaces. Requires unzip
#                              (see packages.txt).
#   snap <name> <confinement> - `sudo snap install <name>
#                              [--<confinement>]`. <confinement> is
#                              typically "classic" or left blank for
#                              strict; checked via `snap list <name>`.
#                              Requires snapd (see packages.txt).
#
# Blank lines and lines starting with '#' are ignored, same as
# packages.txt.

# Code editor - default's dotfiles already wire up editbash/
# editstarship aliases that look for this on $PATH.
curl    fresh     https://raw.githubusercontent.com/sinelaw/fresh/refs/heads/master/scripts/install.sh

# Nerd Font - required for `eza --icons` (all three shells' ls/ll/la/l
# aliases). Every machine tested before the Linux Mint test VM already
# had this font pre-installed by hand, which masked the fact glb
# restore never actually installed it itself - a real fresh-install gap.
font    jetbrains-mono-nerd-font    https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip

# File manager alternative to ranger (kept, not replaced) - stronger
# plugin support (image previews, the git-status plugin configured in
# dotfiles/.config/yazi/). Installed via snap since it's not in apt's
# index on any Debian/Ubuntu-family distro (confirmed empirically on
# Pop!_OS 24.04, apt-cache has no candidate at all) - snap was chosen
# because that's genuinely how it's installed on Greg's real laptop,
# not picked in the abstract. Needs --classic confinement. On pacman
# specifically, this line is routed to a real native `yazi` pacman
# package instead of snap entirely (see _GLB_SNAP_NATIVE_OVERRIDES in
# lib/extras.sh) - confirmed 2026-08-16. Confirmed real gap on zypper
# (see packages.txt) - snapd itself isn't available there and there's
# no native yazi package either, so this entry is a documented no-op on
# openSUSE rather than a GLB bug. Known gap there, not being chased
# further (same call as lazygit on Fedora/dnf).
snap    yazi      classic

# CPU architecture info banner (James Tigert / kz6fittycent), pairs
# with fastfetch's general system-info banner (packages.txt). Strict
# confinement - no --classic needed, confirmed via the snap's own
# install page (snapcraft.io/install/cpufetch/ubuntu). Version 1.07 at
# the time this was added (2026-08-17). Unlike yazi above, this has no
# _GLB_SNAP_NATIVE_OVERRIDES entry, so it hits the normal manual-step
# pause on pacman (snapd deliberately skipped there, see packages.txt)
# and on zypper (snapd not in the default repos at all) - same known-gap
# treatment as yazi's own snapd dependency on those two.
snap    cpufetch
