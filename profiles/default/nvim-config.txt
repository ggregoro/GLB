# change to pick them up. A machine without access to this repo (i.e.
# anyone who isn't Greg) gets a clean "clone failed" message and an
# otherwise-normal restore; nvim still installs, it's just unconfigured.
# Set GLB_NVIM_CONFIG_REPO in the environment to point at a different
# repo. Mirrors GWB's Install-GwbNvimConfig - see
