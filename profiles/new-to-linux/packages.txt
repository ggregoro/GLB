# GLB profile: new-to-linux
#
# A gentle on-ramp for someone switching from Windows/macOS: the same
# curated shell/prompt setup as `default`, with a terminal-based code
# editor (Fresh, via extras.txt below), and nothing else. GLB doesn't
# install GUI applications (browsers, office suites, image editors,
# media players) — those are easy for anyone to install themselves once
# they've found their way around a real terminal, and picking one on
# someone's behalf is a bigger, more opinionated commitment than a shell
# config. See docs/PHILOSOPHY.md ("Enhance the Terminal You Have, Don't
# Replace It") for the reasoning.
#
# Package names are resolved per-distro before being passed to your
# package manager (apt/dnf/pacman/zypper). See _GLB_PACKAGE_OVERRIDES
# in lib/package.sh for the few that aren't the same everywhere.

# Shell/prompt foundation — same unified bash/zsh/fish + Starship setup
# as the default profile (see dotfiles/). git/curl are needed for the
# Starship + zsh-plugin install steps glb_apply_profile always runs;
# fzf/eza/bat/zoxide are referenced directly by the shell aliases.
